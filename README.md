# 手绘风格动画关键帧工作台 · keyframe-workbench

**给非 Claude 系列模型的手绘动画方案。** 水彩晕开、线条会「沸」、一帧一帧重绘出来的精致手绘动画，最早出自 Claude 生态里那套管线（见下方参考项目），吃的正是模型对代码和画面的手感。这里把它拆成工序明确的方法论加模板——沸线节拍、洇墨叠印、飞白侵蚀、横带切片都写死了，模型只管对着规范写场景。GPT、Gemini、DeepSeek、Qwen 换哪个模型，同一套工序照样成立。

配套的控制台按 AE 惯例来：关键帧轨道（dope sheet）、曲线编辑器（graph editor）、变速走带——且轴上每个元素都是真功能：能点、能拖、能改、能删，不是摆设。

## 站在制作流程的哪一环

对照 AI 剪辑的位置更好理解：ChatCut 之于专业剪辑，就是 keyframe-workbench 之于 AI 动画——**AI 先把片子生出来，你在专业工具里粗调，最后一公里交回专业软件精修**。

面向的人群是**用代码做小体量 PV / 短片 / 动画的 UP 主、博主、独立创作者**（不是大型动画工作室）。典型工作流：

```
AI/代码生成动画 → 本工作台粗调（节奏/关键帧/曲线/切点） → 导出 → AE 精修成片
                    ↑ 本仓库只做这一环
```

它不抢 AE 的活，也不替代你的生成管线——它把"AI 出片后、进 AE 前"最费时间的那段调整，从改代码等重渲变成专业动画师熟悉的拖拽操作。

## 为什么要有这个 skill

- **专业动画师**：看到的是熟悉的东西——关键帧菱形、拖动 retime、曲线手柄、J/K 跳帧。上手即用，不用学新交互。
- **不专业的人**：也能像专业动画师那样做动画——所有编辑都落在受约束的数据层上，动画师的基本功（居中/连贯/完整三原则）由原则检查器替你把关，改出耦合冲突会显式亮出来让你裁决，而不是悄悄出错。
- **AI**：也能像专业动画师一样做事——数据层就是 AI 可读写的操作面，AI 的改动走补丁进控制台、琥珀描边、人来接受或还原。AI 产出，专业流程收口。

一句话：**动画内容由每个使用者（或其 AI）现场创作，本仓库提供的是"手绘质感怎么按工序做出来、动画怎么专业地调"这两层的方法论与模板。**

## 每块工作台都是按你的片子长出来的

给的不是装好即用的成品，是一副骨架加一套方法论。`template/` 里那套轨道条、曲线编辑器、走带是通用能力，其余全是变量：

- **轨道有几条**：你这部片子实际在调什么（相机推拉、角色位置、笔触湿度、文字进度），轨道就长几条；
- **面板上的旋钮**：做水墨片，面板是洇染半径、纸纹、笔锋湿度；做角色表演，是表情、视线、姿态；做文字动效，是字距、手写进度、飞白强度；
- **原则规则表**：耦合关系按你的片子写——动了这个部位，哪颗球亮、提示什么冲突；
- **镜头块、拍点、预览帧路径**：跟你的分镜走。

你只需要把要做什么说清楚（题材、时长、镜头、哪几处想反复调），再把 `SKILL.md` 交给 AI，由它按你的项目把接入点接进去。同一个模板，十个项目会长出十块不一样的工作台——定制的是这部片子的参数结构，不是换个皮肤。

## 这是什么 / 不是什么

**是**：

- 一份指导手册（`SKILL.md`）：手绘质感工序、三条工程铁律、PP.keys 数据层规范、五步工作流、验证门、性能手法；
- 一套已通过整体验证的前端模板（`template/`）：可编辑轨道条 + 曲线编辑器 + 走带 + 编辑操作层；
- 一个完整案例（`examples/`）：15 秒生成式 PV 的真实工程数据与验证数字；
- 深入参考（`references/`）：零漂移验证法、原则检查器设计、逐帧手绘踩坑实录。

**不是 / 不包含**：

- **不含动画内容**——拍什么、多长、什么风格，由使用方自己创作；
- **不含后端**——纯前端单文件，数据层就是全部状态；
- **不含渲染依赖库**（如 p5.js）——模板引用的 `lib/*.js` 请按你项目自行放置；
- **不含视频导出器**——成片渲染走你自己的管线（headless Chrome 逐帧 + ffmpeg 等），模板只负责"调"；
- 模板默认中文界面、桌面 Chrome。移动端未适配。

## 30 秒跑起来

1. 把 `template/` 复制进你的项目；
2. 改 4 处接入点（`workbench.html` 头部注释有精确标注）：script 依赖、右面板旋钮、预览帧路径、原则规则表——自己改，或把 `SKILL.md` 交给 AI 按你的项目改，都行；
3. 双击打开（file:// 或静态服务），`?t=8.6` 直达某时刻，`?sel=轨id` 直达曲线模式。

前置要求见 `SKILL.md` 的"核心不变量"：你的渲染器必须提供 `window.renderAt(t, mime, quality)` 单帧出图与 `window.ready`，帧必须是时间的纯函数。

## 参考项目

动画管线建立在这两个开源项目之上：

- **[ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase)** — John Heibel 的 p5.js + p5.brush 手绘动画基座：Clawd 角色系统（视角 / 情绪 / 表情 / 道具挂点）、绘画与时间工具、镜头与笔触转场、headless Chrome 逐帧渲染器。本仓库的手绘管线即基于它搭建；「每一帧独立绘制、线条会沸」的手工质感标准与每秒 12 次的重画节拍也来自它。MIT © 2026 John Heibel。
- **[PDoomVideo](https://github.com/JohnHeibel/PDoomVideo)** — 上述基座的前身：Claude 生成音乐 MV《I'm Upping My P(doom)》的全部源码，Clawd 角色与那份 `ANIMATION_GUIDE.md` 最初在此成形。

底层库：[p5.js](https://p5js.org)、[p5.brush](https://github.com/acamposuribe/p5.brush)。
